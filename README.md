# 🍰 Sweet Crumbs Bakery – Cake Shop Website

Welcome to **Sweet Crumbs Bakery**, a modern and responsive cake shop website designed to make cake browsing and online ordering simple, smooth, and enjoyable. Explore delicious cakes for birthdays, weddings, anniversaries, and other special occasions.

## ✨ Features

* 🏠 Beautiful and modern homepage
* 🎂 Browse a variety of delicious cakes
* 🎉 Birthday, wedding, chocolate, and custom cakes
* 🔍 Search and filter cake products
* 🛍️ Product details with images and prices
* 🛒 Add to cart and manage quantities
* 🎨 Custom cake ordering options
* 📦 Checkout and order management
* 👤 User registration and login
* 🛠️ Admin dashboard for managing products and orders
* 📩 Customer contact form
* 📱 Fully responsive design for mobile, tablet, and desktop
* ✨ Smooth animations and interactive UI

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* MongoDB, if required by the backend

### 1. Clone the Repository

```bash
git clone https://github.com/kanmani-design/Cake-Shop.git
```

### 2. Navigate to the Project

```bash
cd Cake-Shop
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file and add the required configuration for your application.

Example backend configuration:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
```

Keep your real credentials private and never upload `.env` files to GitHub.

### 5. Run the Website

```bash
npm run dev
```

Open the local URL displayed in your terminal.

If your backend is in a separate folder, install its dependencies and start it separately using the scripts defined in its `package.json`.
